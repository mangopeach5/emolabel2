# 한국어 STT 검증 계획

실제 성능 평가는 사용 권한과 참여 동의가 확인된 로컬 녹음만 사용한다. 원본 음성은
외부로 전송하지 않는다. 모의 Whisper 결과 단위 테스트와 실제 모델 평가는 구분한다.

## 최소 테스트 세트

- 서로 다른 성인 화자와 말하기 속도
- 3초, 12초 경계와 12초를 넘는 문장
- 평서문, 의문문, 감탄문, 문장부호가 불분명한 구어체
- 고유명사, 숫자, 외래어, 감정 표현
- 무음, 합성 톤, 배경음, 낮은 음량
- 발화 중 장면 전환과 VAD 무음 경계

각 음원에는 사람이 확인한 원문, 발화 시작·종료, 가능한 경우 단어 경계를 별도로
기록한다. 원문 보존 CER와 평가용 정규화 CER를 둘 다 보고하며 한국어 띄어쓰기 때문에
WER만 단독 지표로 사용하지 않는다. 단어 타임스탬프는 시작/종료 MAE와 허용 오차 내
비율을 보고한다. 사람 정답이 없으면 정확도나 타임스탬프 오차를 계산하지 않는다.

Whisper의 문장부호는 보조 증거일 뿐 문장 완결성 정답이 아니다. 저신뢰도, 높은
no-speech 확률, 반복 압축률, VAD 불일치는 `deferred` 근거가 된다. 동일 영상과 동일
VAD 결과에서 STT 적용 전후의 후보 수와 사람 승인률을 비교한다.
