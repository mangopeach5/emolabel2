# 영상 권리·개인정보·모델 출처

- YouTube Data API v3는 메타데이터 조회용이며 영상 파일 다운로드 권한을 부여하지 않는다. 영상·음성 파일은 권한이 보장된 자료로부터 처리한다.
- 사용자 동의 없이 녹음·대사·사람 얼굴·주석·연구실 코드·API 키를 외부 서버/클라우드로 보내지 않는다.
- 로컬 모델 설치 시에도 모델 파일의 다운로드 출처와 라이선스를 확인한다. 간접 Hugging Face Hub 다운로드를 차단한다.
- 기존 파일을 삭제하거나 overwrite하지 않고, 파생 파일과 원본의 관계를 기록한다.
- 얼굴 존재를 근거로 신원이나 실제 발화자를 단정하지 않는다.
- AI가 판단한 감정은 예측이며, 사람이 최종 승인해야 연구 정답이다.
