이제 문서에서 합의한 Phase 1을 구현해 줘. AGENTS.md 안전 규칙 준수.

- 새 프로젝트 폴더 내부만 수정한다. GitHub/git, Hugging Face, 모델 다운로드, 외부 API 사용 금지.
- 로컬에서 승인된 파일만 등록하는 manifest 검증과 기본 중복 확인을 구현한다.
- 작업 단계별 처리 시간과 성공/오류 로그를 남긴다.
- 검수 상태(`candidate`, `prelabelled`, `accepted`, `rejected`, `uncertain`)를 명확히 분리한다.
- 명시적으로 accepted된 클립만 export할 수 있는 데이터 구조를 구현하되 원본 데이터는 수정하지 않는다.
- 유닛 테스트(정상/경계/거절/중복/실패 케이스)는 네트워크 없이 실행한다.
- 각 함수의 역할·입출력을 설명하고, 실행 명령과 테스트 결과/실제 측정치/한계를 보고한다.
- 아직 영상 AI 처리, YouTube API, Ollama 실사용, 원본 EmoLabel 연동은 하지 않는다.
